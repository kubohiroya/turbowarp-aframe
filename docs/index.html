TurboWarp-A-Frame

TurboWarp-A-Frame is an unsandboxed TurboWarp extension for building declarative A-Frame scene graphs from blocks.

Scene model

Scratch sprites and backdrops are script containers. The 3D graph is addressed through node ids, classes, data attributes, A-Frame attributes, templates, selectors, and events.
